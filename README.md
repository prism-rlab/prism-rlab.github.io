# PRISM Lab Website

Website for the PRISM Lab: Probabilistic Intelligent Systems and Machine Learning.

The site is designed to be maintained with simple Jekyll data files:

- `_data/research.yml` for research themes
- `_data/people.yml` for lab members
- `_data/publications.yml` for selected publications
- `_data/news.yml` for updates

Figures and photos can be added under `assets/img/` and referenced from the data files or pages.

The lab logo source is stored at `assets/img/prism-logo.pdf`; the website uses `assets/img/prism-logo.png`.

UMass Boston assets are stored as `assets/img/umb-logo-blue.svg`, `assets/img/umb-campus-aerial.jpg`, and `assets/img/umb-welcome.jpg`.

## Local Preview

If you have Ruby and Bundler installed:

```bash
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
